### 4.2 Hasil Pengujian White Box
Berikut adalah laporan eksekusi pengujian internal yang dilakukan secara nyata terhadap kode program Sistem Informasi Pengaduan Masyarakat di lingkungan *localhost* (XAMPP):

| ID Test | Model Pengujian | Deskripsi Pengujian Internal | Hasil yang Diharapkan (Expected) | Hasil Aktual (Actual) | Status Akhir | Keterangan / Catatan |
|---|---|---|---|---|---|---|
| **WB-01** | Desk Checking | Memeriksa perubahan nilai variabel `$status_laporan` secara manual dari nilai awal '0' menjadi '1' saat Admin menanggapi pengaduan. | Variabel berubah secara logis tanpa menyebabkan nilai *null* atau *error data type*. | Variabel berubah dari '0', '1', hingga '2' (Selesai) secara konsisten di memori sistem tanpa error. | **PASS** | - |
| **WB-02** | Code Walkthrough | Meninjau baris kode penanganan *session login* bersama untuk memastikan penggunaan fungsi `mysqli_real_escape_string()`. | Logika sanitasi input aman dan dipahami oleh seluruh anggota tim pengembang. | Seluruh query database untuk modul pengaduan telah dilindungi fungsi sanitasi input dengan benar. | **PASS** | - |
| **WB-03** | Formal Inspections | Memeriksa ketepatan format pesan validasi data kosong (*Empty Field*) ketika form pengaduan dikirim tanpa mengisi NIK/laporan. | Sistem memicu fungsi alert/modal "Semua kolom wajib diisi!" dengan format yang tepat. | Validasi memicu pesan error modal "Empty Field" secara tepat apabila input masyarakat kosong. | **PASS** | - |
| **WB-04** | Control Flow Testing | Menguji jalur kendali percabangan logika fungsi `loginAuth()` berdasarkan tingkatan role admin/masyarakat. | Alur logika *control flow* mengarahkan *session user* ke halaman dasbor yang tepat tanpa terjebak *infinite loop*. | Jalur pengalihan hak akses Admin dan Masyarakat berfungsi 100% tanpa ada salah arah tujuan. | **PASS** | - |
| **WB-05** | Basic Path Testing | Mengidentifikasi semua jalur eksekusi independen alur peninjauan laporan menggunakan perhitungan *Cyclomatic Complexity*. | Seluruh jalur keputusan logika (`if-else`) berhasil dieksekusi minimal satu kali tanpa ada jalur yang terlewat. | Semua kemungkinan kombinasi alur status pengaduan lulus uji coba dengan nilai kompleksitas yang aman. | **PASS** | - |
